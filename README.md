## 🧠 What is Food Munch?

Food Munch is a fully responsive food ordering website focused on clean UI, structured navigation, and a smooth experience across mobile, tablet, and desktop. The project emphasizes mobile-first design principles and reusable, component-driven layout patterns using Bootstrap.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 📱 **Fully Responsive** | Mobile-first layout that adapts cleanly across all screen sizes |
| 🧭 **Structured Navigation** | Smooth scrolling between sections for an app-like feel |
| 🍽️ **Categorized Menu** | Interactive, organized menu sections by food category |
| 🎯 **Reusable UI Components** | Clean, consistent components built with Bootstrap |
| 💳 **Delivery & Payment Section** | Dedicated visual section for delivery and payment info |
| 🎁 **Modal Interactions** | Gift/redeem feature implemented via interactive modals |
| 🌐 **Cross-Browser Compatible** | Tested for consistent rendering across major browsers |

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/saikumarbulasala/Food-Munch-Website.git
cd Food-Munch-Website
```

### 2. Run locally

No build step needed — just open the file directly:

```bash
open index.html
```

Or serve it with a simple local server (recommended for consistent behavior):

```bash
npx serve .
```
